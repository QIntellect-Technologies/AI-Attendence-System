  • Poll activity every 2 seconds

================================================================================
  CUSTOMIZATION OPTIONS
================================================================================

Change Layout Ratio
  • Default: 70% video, 30% activity
  • To make video larger: Adjust flex values in CSS

Change Colors
  • Default: Dark theme with indigo accent
  • To use different colors: Update CSS variables

Add More Cameras
  • Add new camera tab HTML
  • Update switchCamera() function
  • Add corresponding API endpoint

Change Update Frequency
  • Default: 2 seconds for activity, 3 seconds for stats
  • To change: Update setInterval() values in JavaScript

Issue: Mobile layout not working
Solution: Check viewport meta tag and responsive CSS
