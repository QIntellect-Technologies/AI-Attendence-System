================================================================================
  🎯 SYSTEM OVERVIEW
================================================================================

WHAT IT DOES:
  • Monitors live video feeds from NVR/DVR cameras
  • Detects faces in real-time using YOLOv8
  • Recognizes faces using InsightFace embeddings
  • Tracks faces persistently with identity locking
  • Logs attendance with biometric confidence scores
  • Displays real-time detection ticker

ARCHITECTURE:
  Flask Web Server
    ├─ Enrollment Pipeline (upload video → extract embeddings)
    ├─ Recognition Pipeline (single frame recognition)
    └─ Live Stream Pipeline (real-time monitoring)
         ├─ Thread 1: Grabber (30-60 Hz) - pulls latest frame
         └─ Thread 2: AI Worker (3 Hz) - processes asynchronously

TECHNOLOGIES:
  • Face Detection: YOLOv8 Nano
  • Face Recognition: InsightFace (buffalo_l)
  • Video Streaming: RTSP + OpenCV
  • Web Framework: Flask + CORS
  • Database: SQLite
  • Threading: Python threading
  • GPU Support: CUDA (optional)

================================================================================
  ⚠️ CURRENT ISSUES & SOLUTIONS
================================================================================

ISSUE 1: FLICKERING BETWEEN RECOGNIZED/UNKNOWN
  Root Cause: Training data mismatch
    • Model trained on close-up WhatsApp video
    • NVR camera at 6-8 feet produces different embeddings
    • Similarity scores hover around threshold (0.58-0.62)
  
  Current Solution: Temporary threshold reduction (0.60 → 0.55)
    • Catches more borderline matches
    • Reduces flickering
    • Trade-off: More false positives
  
  Permanent Solution: Retrain with NVR video at 6-8 feet
    • Record new training video at proper distance
    • Extract embeddings from NVR video
    • Similarity scores will be 0.75-0.85 (confident)
    • Restore threshold to 0.60-0.65
    • Timeline: 1-2 hours
  
  Status: KNOWN & ADDRESSED ✅

ISSUE 2: SINGLE GPU BOTTLENECK
  Root Cause: YOLO and InsightFace compete for GPU memory
  
  Current Solution: Throttle processing
    • InsightFace extraction every 0.5s
    • Process only top 6 faces per frame
    • CPU fallback available
  
  Future Solution: Multi-GPU support
    • YOLO on GPU 1, InsightFace on GPU 2
    • Batch processing
    • Model quantization
    • Timeline: 2-3 weeks
  
  Status: KNOWN & MANAGEABLE ✅
