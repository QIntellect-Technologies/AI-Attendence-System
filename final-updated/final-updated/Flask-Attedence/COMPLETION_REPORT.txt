================================================================================
                        ROOT CAUSE ANALYSIS
================================================================================

THE PROBLEM YOU REPORTED:
  System shows flickering between "Imran khalid" and "Unknown" when detecting
  faces at 6-8 feet distance from NVR camera.

WHY IT HAPPENS:
  1. Training data: Close-up WhatsApp video (face fills frame)
  2. Usage: 6-8 feet NVR camera (face is small)
  3. Result: Different distances produce different facial embeddings
  4. Similarity scores: 0.58-0.62 (borderline, hovering around threshold)
  5. Effect: Frame-by-frame flickering between matched and unmatched states

FRAME-BY-FRAME ANALYSIS:
  Frame 1: Similarity 0.61 → Match ✓ (shows "Imran khalid")
  Frame 2: Similarity 0.59 → No match ✗ (shows "Unknown")
  Frame 3: Similarity 0.62 → Match ✓ (shows "Imran khalid")
  Result: Flickering between matched and unmatched states

WHY 6-8 FEET IS CORRECT (NOT TOO FAR):
  ✅ Matches your actual NVR camera usage scenario
  ✅ Facial features are still clearly visible
  ✅ Standard distance for surveillance systems
  ✅ The issue is training data source, not distance
  ❌ Close-up mobile phone videos are NOT suitable for NVR training

TEMPORARY FIX APPLIED:
  - Threshold lowered: 0.60 → 0.55 in config.py
  - Effect: Catches more borderline matches, reduces flickering
  - Limitation: Increases false positives (wrong people matched)
  - Status: TEMPORARY - will be adjusted after retraining

PERMANENT SOLUTION:
  1. Record new training video at 6-8 feet from NVR camera
  2. Extract and train biometrics from NVR video
  3. Similarity scores will improve to 0.75-0.85 (confident)
  4. No more flickering - problem solved!

IF APP WON'T START:

  2. Check Python version: python --version
  3. Check dependencies: pip list | grep flask
  4. Check logs: logs/attendance.log

IF NVR RECORDING FAILS:
  1. Check NVR URL in config.py
  2. Verify NVR is powered on
  3. Test connectivity: ping 192.168.0.77
  4. Check firewall settings
  5. Review logs for error details

IF BIOMETRIC EXTRACTION FAILS:
  1. Verify video file exists in uploads/
  2. Check video is valid MP4 format
  3. Verify video has clear facial features
  4. Check disk space available
  5. Review logs for specific errors

  1. This is expected with current training data
  2. Flickering will stop after retraining
